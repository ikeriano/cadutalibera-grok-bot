# Caduta Libera / ¡Ahora caigo! · versión 1.0 (privado)

Juego de fans hecho por Iker a partir de la app móvil de Caduta Libera. Idiomas: italiano (por defecto) y español.

- `www/`: juego web (three.js). Tiene el modo 2D clásico de la app (`clasico_cl/`) y el Modo Programa 3D con todos los extras.
- `android/`: proyecto Android con WebView (com.ikeriano.cadutalibera). El APK firmado está en la release v1.0.
- `roblox/`: CadutaLibera-AhoraCaigo-Plato.rbxlx (solo el plató) y CadutaLibera-AhoraCaigo-Juego.rbxlx (juego completo), más el generador en `roblox/codigo/`.
- `ep3000_it/`: guion y voces del episodio «Caduta Libera nell'anno 3000» (Tomas falsas).
- `promo_ia/`: «Hacer mis propias promos» con plantillas IT/ES.
- `extraccion/`: herramientas de extracción del APK y Lua descompilado.
- `capturas/`: capturas de pantalla.

Voces: Piper medium/high (it_IT-paola-medium y voces es_* medium/high). Nunca modelos -low ni la voz del navegador.
